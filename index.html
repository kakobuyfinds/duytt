From product link to parcel

  1. Save the exact listing. Keep the source URL, variant, current price, and the date you checked it. If you plan to use LitBuy, confirm that it accepts the original listing.
  2. Compare actual measurements. Record the measurements in centimeters. For shoes, distinguish foot length from insole length. For clothing, compare flat measurements with an item that fits.
  3. Review warehouse quality control (QC). Compare the photos with the ordered color and size. Check seams, closures, and visible damage. Ask about the exchange window as soon as you spot an issue.
  4. Compare shipping quotes for the same parcel. Use the same destination, packed dimensions, and weight with each quote. Check which charges are prepaid and which could be collected at delivery.

Frequently asked questions

What is a LitBuy spreadsheet?

It is a shopping shortlist you can use to compare product links, prices, variants, and notes before placing an order with a shopping agent. This guide uses CAFANS listings as its starting catalog.

Can I use a CAFANS listing with LitBuy?

Open the CAFANS product page and look for the available shopping-agent links or the original seller listing. Confirm that LitBuy can load the listing and the variant you want before paying.

Why can the shipping quote change after packing?

Some shipping lines compare the parcel’s actual weight with a weight calculated from its dimensions. Protective packaging and shoe boxes can increase the billable weight. Ask the agent which weight the selected line uses and whether the quote includes taxes.
